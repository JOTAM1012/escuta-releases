# Escuta

Grava aulas, reuniões e conversas; transcreve, separa as vozes e resume com IA — de graça.

## Instalar

1. No celular, abra **[a última versão](https://github.com/JOTAM1012/escuta-releases/releases/latest)**.
2. Baixe **`Escuta.apk`** e abra o arquivo (permita "instalar apps desta fonte" quando o Android pedir).
   - Celular antigo (32 bits)? Use `Escuta-celular-antigo-32bits.apk`.
3. Pronto. Daqui pra frente o próprio Escuta avisa quando houver versão nova e se atualiza.

No primeiro uso, o app explica como criar as chaves grátis (Groq e Gemini) em Configurações.
